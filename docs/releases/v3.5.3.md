# Taiko Fancy Arranger v3.5.3

A new NSO theme, osu!'s editor keys, smoother scrolling, a faster launch, a redesigned Settings window and a reworked Import Image as Drawing.

## Updating to this version

From v3.4.2 or later, click **Update and Restart**. From v3.4.1 or earlier, download it by hand once; see the v3.4.2 notes.

## New

- **NSO theme.** A Needy Streamer Overload desktop: light pink windows with black text on the striped sticker wallpaper, pink lanes, and Windows' own title bar in the theme's pink. Its text is M PLUS Rounded 1c, which covers Japanese too, and its window titles use Press Start 2P. Both fonts are SIL OFL and ship with the app.
- **osu!'s editor keys** on the Editor and Gimmick pages: Left/Right step one snap (Shift for four), Ctrl+Left/Right jump between notes, Alt+Left/Right between bookmarks, Q W E R toggle new combo / whistle / finish / clap, Shift+1..9 set the beat snap, Ctrl+G reverses the selection, Ctrl+X cuts and Ctrl+D clones one measure on. Up/Down move focus between views. All of them can be rebound in Settings.
- **Settings redesign.** A sidebar with a search over every page, card rows, switches you can flip from anywhere on the row, theme swatches drawn in each theme's colours, and shortcut chips that mark clashes as you type.
- **Import Image as Drawing** has a live preview with examples for each option. Changing Ignore Specks or Smoothing no longer traces the picture again, which took about 2s on a 1024px screenshot. You can also drop a picture onto the dialog.

## Changed

- **The density bar follows the theme**, a gradient in the theme's own colour, brighter where the chart is denser. It was white-to-yellow in every theme.
- **Sliders are themed everywhere.** The AR, CS and Background sliders were drawn as plain white Windows sliders.
- **Song select's difficulty rows drop the mapper's name**, which the song row above already shows.
- **Smoother scrolling.** Frames are paced to your display's refresh rate rather than a fixed 120fps, which made a 20Hz judder on a 100Hz monitor. Notes move in quarter pixels instead of snapping to whole ones. A 12–13ms garbage-collection pause that could land mid-scroll is gone.
- **Faster launch and map opening.** The window builds in 590ms instead of 670ms, and osu!.db reads in 140ms instead of 230ms. Opening a map takes 325ms instead of 626–1280ms the first time and 76ms instead of 360ms after that, because the difficulty list no longer parses every file in the folder.

## Fixed

- **Song select showed the wrong song after the Editor tab.** Pick a song while one is open, go back to the Editor by its tab, then return: the list showed the picked song while the open one played. It now goes back to the song being edited.
- **A long difficulty name was pushed down** in the view's name box when the pointer hovered over the view.
- **The gameplay preview's built-in barline** was drawn in the theme's colour instead of white.
- **A shape could leave the playfield** in the Fancy Arranger: a position offset kept from earlier, or a centre at the edge with a large radius, placed notes past the edge (x=690 on a Circle). Applied notes are now kept on the playfield.
- **The playhead could jump back to the map's start for about 90ms** when seeking straight after opening a map.
