# Taiko Fancy Arranger v3.5.4

osu!'s Z/X/C keys, a Generate SV dialog you can drive from the keyboard, and fixes for spinners, view headers, the mods chip and Enter in dialogs.

## Updating to this version

From v3.4.2 or later, click **Update and Restart**. From v3.4.1 or earlier, download it by hand once; see the v3.4.2 notes.

## New

- **Z / X / C**, as in osu!'s editor: Z jumps to the first note, X goes to 00:00 and plays, C is a second Play/Pause. All three can be rebound in Settings.
- **Generate SV from the keyboard.** The dialog opens with the initial rate selected: type a value, Tab to the final rate, Enter to generate. The position offset is remembered, so it is set once.
- **Replace existing green lines.** Removes the green lines in the range before writing the new ones, in one undo step. On a gimmick layer it removes only that layer's lines.
- **Multiply initial / final by** a constant (default ×1.10), each with its own checkbox and factor, remembered. The prefilled rate opens already multiplied; unticking divides it back.
- **Remember last choice** for the curve.
- **Scroll step** for the rate boxes, at the top right of the dialog, default 0.01.

## Changed

- **Generate SV reads the rates at the first and last notes** in the selection, not at the edges of the drag. A selection starting just before a note's green line now reads that line's SV (2.70) and not the one before it (2.00).
- **The curve description** reads "How the value moves from initial point to final point."
- **The mods chip is hidden on song select** and comes back in the editor. Opening a different difficulty from song select clears the mods; reopening the same one keeps them.

## Fixed

- **Enter in a settings sheet pressed Restore defaults.** In every sheet dialog (Generate SV, the gimmick configs, Convert Notes), Enter went to Restore defaults, hidden or not, instead of the pink action button.
- **Clicking a view's header did not select that view.** It now does; dragging the header to reorder is unchanged.
- **A spinner could only be grabbed by its head.** It can now be selected, moved and deleted anywhere along its duration, and the whole band is outlined when selected.
- **Click-holding a spinner showed a yellow slider.** The move preview now shows a faded spinner.
