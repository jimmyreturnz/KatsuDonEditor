# Taiko Fancy Arranger v3.5.7

Two tools on the Miscellaneous page: Taiko to Mania, which turns a taiko difficulty into a 4K or 1K osu!mania chart played the way the autoplay plays it, and a Mappack Creator that gathers difficulties from any sets into one set you can submit.

## Updating to this version

From v3.4.2 or later, click **Update and Restart**. From v3.4.1 or earlier, download it by hand once; see the v3.4.2 notes.

## New

- **Taiko to Mania.** Writes a new osu!mania difficulty into the same set.
  - **4 Keys** puts each note in the column of the drum half the autoplay hits, so every playstyle, binding and the left-handed option carry over. **1 Key** is one column.
  - **Drumrolls and spinners become hold notes** in that hand's don column. Fake sliders are dropped.
  - **The scroll is the chart BPM's.** Every red line gets a green line that cancels its BPM: a 428 BPM section in a 214 BPM chart scrolls at 2.0x. Other green lines go, except where kiai or volume changes.
  - **Hitsounds are written on each note.** With **Include hitsounds from the current skin** on, the current skin's taiko sounds are copied into the set; a set's own sample by the same name stays for its taiko difficulties.
  - **Hit finishers as single note** makes a finisher one note instead of two. **Single tap BPM** sets the beat the playstyle groups notes against, and starts at the chart's BPM.
  - **Convert osu!'s current difficulty** converts whatever osu! has selected, without opening it here.
- **Mappack Creator.** Difficulties from different sets become one set in your Songs folder, with your Title and Creator, Various Artists as the artist, `BeatmapID:0` and `BeatmapSetID:-1`.
  - **Adding a difficulty:** the button while it is selected in osu!, **Alt+Shift+A** from anywhere (osu! included), or **Ctrl+Shift+=** on this app's song select.
  - **Each difficulty is named** `Artist - Title (mapper) [Difficulty]` by default, and the name can be edited in the table.
  - **One background for every difficulty**, by Select or by dropping an image, or each keeps its own. The selected difficulty's own background shows beside it.
  - **Identical files are stored once.** Two difficulties sharing a song or an image share one file.
  - **Size and difficulty meters** against osu!'s limits: 5 MB plus 10 MB per minute of the longest difficulty, at most 100 MB, and 128 difficulties.
  - **A "Delete" difficulty** (on by default): two objects 15 minutes apart over silent audio, which lifts a pack of short songs to the 100 MB cap. Submit from the longest difficulty; the page says which one and why.
  - **Tags:** every difficulty's tags are collected, each word once, into a box you can edit, with a 1000-character count. The Delete difficulty is written with exactly these. **Remove duplicates** ignores capitals. The original mappers are added to every difficulty's tags (optional).
  - **Load osu!'s current pack** to edit a pack made earlier: add or remove difficulties, change the tags, then **Update pack**. The new set is written first, and only then does the old one go to the Recycle Bin. **Export new pack** writes a separate copy.
- **The Metadata page's Tags box is taller**, and turns red past 1000 characters.

## Fixed

- **Dropping the same background image twice onto Fancy Arranger stored it twice.** A byte-identical file already in the set is reused.
- **A map whose audio name differs in case from the file** is found, as osu! finds it on Windows.
